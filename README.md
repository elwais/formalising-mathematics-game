This is an unofficial [`lean4game`](https://github.com/leanprover-community/lean4game) recreation of [Kevin Buzzard's *Formalising Mathematics* course](https://www.ma.imperial.ac.uk/~buzzard/xena/formalising-mathematics-2024/). This course serves to provide a personal proof-of-concept on gamifying mathematics for use in courses in the University of Hawaiʻi at Mānoa. This game assumes the player is an undergraduate in a mathematics-heavy field of study (such as mathematics itself, computer science, engineering, and so forth). Its content will mirror that of *Formalising Mathematics*, but notes, comments, and annotations will differ noticeably.
